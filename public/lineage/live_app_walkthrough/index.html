What You Are Looking At
GhostLine is one workspace with five visible parts: top controls, the main viewer, a playback bar, a research sidebar, and a few extra pop-up tools.
What Happens When You Run It
You ask the model something, the backend starts generating, GhostLine receives the stream, slows it down to something watchable, and then draws it on screen.
What Replay Does
A live run can be saved as a recording. That recording can be loaded back in later and stepped through again without needing the model to run live.
What The Side Tools Are For
The sidebar is where GhostLine turns from a viewer into a research tool: choose signals, compare runs, test ideas, and organize prompt sets.
What The Controls Change
The top-level controls mainly change three things: how the workspace is arranged, what project you are in, and which backend GhostLine is talking to.
