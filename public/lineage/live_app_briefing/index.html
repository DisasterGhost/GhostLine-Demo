How GhostLine Works

A visual walkthrough of GhostLine's moving parts — what you see on screen, how data flows, and where the research tools fit in. Start here for the big picture.
→ Technical deep-dive → Full architecture index
What you're looking at
Five panels that work together: a control bar for prompts, a viewer for 3D trajectories, replay controls, a research sidebar, and floating tools for settings and token inspection.
How live generation flows
You type a prompt. The backend generates tokens one at a time. Each token arrives with its geometry, gets buffered so you can watch at human speed, then appears on screen.
How replay works
Every generation is automatically recorded. You can save it, load it back later, scrub through it token by token, and inspect any moment — no backend needed.
Where the research tools fit
The research sidebar sits right next to the viewer. It reads the same signals and sessions you're already watching — compare runs, test hypotheses, sweep parameters.
How you control it
Switch between layout presets, save your workspace, and point at a local or remote GPU backend — all from the same interface.
